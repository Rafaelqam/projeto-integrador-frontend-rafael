# projeto-integrador-frontend-rafael

## Catálogo de Peças de Computador

Projeto desenvolvido para a disciplina de Projeto Integrador, com o objetivo de criar uma página web para apresentar informações sobre peças de computador.

O site possui um catálogo de componentes de hardware, apresentando informações sobre cada peça e um formulário para solicitação de informações.

## Objetivo

Desenvolver uma página web organizada e semântica, aplicando conhecimentos de HTML5, CSS3 e JavaScript.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Peças disponíveis

* Processador AMD Ryzen 5 5600
* Placa de vídeo GeForce RTX 4060
* Memória RAM Kingston Fury 16 GB
* SSD Kingston NV2 1 TB

## Funcionalidades

* Catálogo de peças de computador
* Exibição de imagens dos produtos
* Informações e preços das peças
* Tabela de comparação
* Formulário de solicitação de informações
* Seleção da peça de interesse
* Opções de contato por e-mail ou telefone
* Validação dos campos do formulário
* Estrutura HTML semântica

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para executar o projeto durante o desenvolvimento.
